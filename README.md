# 医学统计学教程大纲（含核心工具）

# 前言：医学统计学的核心价值与学习目标

## 1\.1 核心价值

连接医学研究（临床、基础实验）与数据结论，解决“数据如何支撑医学结论”“如何避免数据误导”，是医学论文、科研项目、临床决策的必备工具。

## 1\.2 学习目标

- 掌握医学统计核心概念，能区分不同数据类型的统计逻辑；

- 熟练运用各类统计工具，匹配不同研究设计的数据分析需求；

- 能独立完成基础统计分析、结果解读，规避常见统计错误；

- 结合医学场景（如临床疗效、流行病学调查），灵活选择工具并应用。

# 第一部分：医学统计学基础（必备前提）

## 1\.1 核心概念辨析

- 数据类型：计量资料（身高、血压）、计数资料（性别、阳性/阴性）、等级资料（疗效分级：治愈/有效/无效）；

- 核心术语：总体与样本、参数与统计量、误差（随机误差、系统误差、过失误差）、P值、置信区间、统计学意义；

- 研究设计类型：横断面研究、队列研究、病例对照研究、随机对照试验（RCT）—— 决定后续统计工具选择。

## 1\.2 数据预处理（统计分析的基础步骤）

- 数据收集：医学数据的特点（完整性、客观性、时效性）及收集注意事项；

- 数据清洗：缺失值处理（删除、填补）、异常值识别（箱线图、Z检验）、数据标准化；

- 数据整理：分组、编码（如计数资料赋值）、数据库建立（Excel、SPSS基础操作）。

# 第二部分：核心医学统计学工具（按应用场景分类）

## 2\.1 描述性统计工具（描述数据分布特征）

### 2\.1\.1 计量资料描述工具

- 集中趋势：均数（算术均数、几何均数、中位数）—— 适用场景（如正态分布用均数，偏态分布用中位数）；

- 离散趋势：标准差、方差、四分位数间距、极差—— 搭配集中趋势使用（如均数\+标准差，中位数\+四分位数间距）；

- 图形工具：直方图、箱线图、折线图—— 直观呈现数据分布（如箱线图识别异常值）。

### 2\.1\.2 计数/等级资料描述工具

- 频数表、构成比、率（发病率、患病率、有效率）；

- 图形工具：条形图、饼图、构成图—— 展示分组占比或频数分布。

## 2\.2 推断性统计工具（由样本推断总体）

### 2\.2\.1 假设检验工具（核心重点）

- 计量资料假设检验：


    - t检验：单样本t检验（样本与总体比较）、两独立样本t检验（两组独立计量资料，如实验组vs对照组血压）、配对t检验（配对设计，如同一患者治疗前后对比）；

    - 方差分析（ANOVA）：单因素方差分析（多组独立计量资料，如3种药物的疗效指标对比）、双因素方差分析（考虑两个影响因素，如药物\+剂量对疗效的影响）、重复测量方差分析（同一对象多次测量，如随访不同时间点的指标）；

    - 非参数检验：Wilcoxon秩和检验（两样本偏态计量资料）、Kruskal\-Wallis H检验（多样本偏态计量资料）—— 适用场景（数据不满足正态分布、方差不齐）。

- 计数/等级资料假设检验：
        

    - 卡方检验（χ²检验）：四格表卡方（两组计数资料，如阳性率对比）、行×列表卡方（多组计数资料）、配对卡方检验（配对设计计数资料，如两种检测方法的阳性率对比）；

    - 非参数检验：Mann\-Whitney U检验（两样本等级资料）、Kruskal\-Wallis H检验（多样本等级资料）、Friedman M检验（配对等级资料）。

### 2\.2\.2 相关与回归分析工具（分析变量间关系）

- 相关分析：

    - Pearson相关系数：计量资料\+正态分布（如身高与体重、血压与年龄的线性关系）；

    - Spearman秩相关系数：等级资料或偏态计量资料（如疗效等级与病程的关系）；

    - Kendall和谐系数：多评价者一致性分析（如3名医生对同一批患者疗效的评分一致性）。

- 回归分析：
        

    - 线性回归：单因素线性回归（单个自变量影响因变量，如剂量与疗效指标的线性关系）、多因素线性回归（多个自变量，如年龄、性别、剂量对疗效的共同影响）；

    - Logistic回归：二分类Logistic回归（因变量为二分类，如患病/未患病、有效/无效）、多分类Logistic回归（因变量为多分类，如疗效分级）—— 核心用于影响因素分析、风险预测；

    - 生存分析：Kaplan\-Meier法（绘制生存曲线，比较两组/多组生存时间）、Cox比例风险回归（分析影响生存时间的因素，如治疗方案、年龄对患者生存期的影响）—— 适用于随访研究、预后分析。

## 2\.3 其他常用医学统计工具

- 样本量估算：核心工具（公式法、软件法），根据研究设计、预期效应量、α值、检验效能估算所需样本量—— 避免样本量不足或过多；

- 一致性检验：Kappa检验（计数资料一致性，如两种诊断方法的一致性）、ICC检验（计量资料一致性，如两台仪器测量血压的一致性）；

- Meta分析：系统评价的统计方法，整合多个同类研究结果，提高结论的可靠性—— 常用工具（RevMan、Stata）。

# 第三部分：统计工具实操（软件结合，落地应用）

## 3\.1 常用医学统计软件介绍与基础操作

- SPSS：最常用（上手简单），重点讲解与医学场景匹配的操作（如t检验、卡方检验、Logistic回归的步骤）；

- Stata：适用于复杂统计分析（如生存分析、Meta分析），基础操作与结果解读；

- Excel：基础统计功能（描述性统计、简单图表），适合初学者快速上手。

## 3\.2 分场景实操案例

- 案例1：临床疗效对比（如两种药物治疗高血压的疗效，用t检验、卡方检验）；

- 案例2：影响因素分析（如糖尿病患病的影响因素，用多因素Logistic回归）；

- 案例3：预后分析（如癌症患者生存期影响因素，用Kaplan\-Meier法、Cox回归）；

# 第四部分：医学统计常见错误与注意事项

## 4\.1 常见统计错误（避坑重点）

- 数据类型与统计工具不匹配（如偏态计量资料用t检验）；

- 假设检验滥用（如多次检验不校正α值，导致假阳性）；

- 样本量不足或抽样方法不当（如随机对照试验未随机分组）；

- 结果解读错误（如将统计学意义等同于临床意义）。

## 4\.2 注意事项

- 统计工具选择的核心：先明确研究设计、再确定数据类型、最后匹配工具；

- 软件操作的关键：数据录入规范（避免编码错误）、参数设置正确；

- 医学论文中的统计报告：需明确说明所用统计方法、样本量、P值、置信区间等核心信息。
