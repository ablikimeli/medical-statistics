前言：核心价值与学习目标

医学统计学的核心价值

医学统计学是连接医学研究（临床试验、基础实验、流行病学调查）与科学结论的桥梁。

价值维度具体体现
研究设计优化样本量估算、随机化分组、对照设置
数据可靠性保障质量控制、偏倚识别、结果验证
结论外推能力从样本推断总体，从现象揭示规律
临床决策支持循证医学、诊疗指南制定
核心问题：
"数据如何支撑医学结论？"
"如何避免数据误导？"

学习目标

  1. 概念掌握：区分数据类型，理解核心统计术语（P值、置信区间）
  2. 工具运用：根据研究设计和数据类型，匹配正确的统计分析方法
  3. 独立分析：使用SPSS/R/Stata完成基础统计分析并正确解读结果
  4. 规避错误：识别并避免常见统计错误
  5. 论文规范：按照国际标准（STROBE、CONSORT）规范报告统计结果

第一部分：统计学基础

数据类型

计量资料（定量资料）

定义：用连续数值表示的资料，具有计量单位。如身高（cm）、体重（kg）、血压（mmHg）等。

指标单位特点
身高，体重cm, kg近似正态分布
血压（收缩压/舒张压）mmHg近似正态分布
血糖、血脂mmol/L可能偏态
肝功能指标（ALT、AST）U/L常偏态分布

计数资料（定性资料）

类型定义示例编码
二分类只有两个互斥类别性别、生死、患病/未患病0/1
无序多分类多个互斥类别，无等级关系血型（A/B/AB/O）1/2/3/4
有序多分类多个类别，存在等级顺序疗效（治愈/有效/无效）1/2/3
注意：等级资料的统计分析应选用非参数检验或专门的有序回归模型，不能简单当作计数资料处理。

核心术语

总体与样本

总体 (Population)：研究者想要推断的全部观察对象的集合
总体参数（Parameter）：μ, σ, π
↓ 抽样
样本 (Sample)：从总体中随机抽取的部分观察对象
样本统计量（Statistic）：x̄, s, p̂
↓ 统计推断
用样本统计量推断总体参数

P值（p-value）

定义：在原假设（H₀）成立的条件下，观测到当前结果或更极端结果的概率。

P值范围结论
P < 0.05拒绝H₀，结果有统计学意义
P ≥ 0.05不拒绝H₀，结果无统计学意义
P < 0.01结果有高度统计学意义
重要提醒：P值不是"效应大小"！P值小不等于效应大，它只说明"结果是否由随机误差引起"。

置信区间（CI）

定义：包含未知总体参数的概率区间。常用95% CI。

解读示例：
某降压药使收缩压平均降低 12 mmHg（95% CI: 8-16 mmHg）

解读：有95%的把握认为该降压药使收缩压降低的真正效果在 8-16 mmHg 之间。

数据预处理

缺失值处理方法

方法适用场景
删除法缺失比例<5%，且为随机缺失
均值填补计量资料，整体缺失率低
回归填补有预测变量时
多重填补缺失较多，需保持变异性（MICE算法）
LOCF随访研究，用最后一次观测值填补后续缺失

异常值识别

  • 箱线图法：异常值定义：< Q1 - 1.5×IQR 或 > Q3 + 1.5×IQR
  • Z分数法：|Z| > 3 考虑为异常值（适用于正态分布）
  • 专业知识判断：如血压超过300 mmHg为明显错误

第二部分：核心统计工具

描述性统计

指标公式适用条件
算术均数 x̄Σxi/n正态或近似正态分布
几何均数 G(x₁·x₂·...·xn)^(1/n)等比资料、对数正态分布
中位数 Md位于50%位置的数偏态分布、分布未知
标准差 s√[Σ(xi-x̄)²/(n-1)]与均数搭配使用
四分位数间距 IQRQ75 - Q25与中位数搭配
报告规范：
• 正态分布：x̄ ± s（如：168.5 ± 8.3 cm）
• 偏态分布：M (Q1, Q3)（如：住院8天 (5, 15)）

推断性统计——假设检验

假设检验基本步骤

Step 1: 建立假设
H₀: 原假设（无差异）
H₁: 备择假设（有差异）
↓
Step 2: 确定检验水准
α = 0.05（常规）
↓
Step 3: 计算检验统计量
t值、F值、χ²值、z值等
↓
Step 4: 确定P值，作出推断
P < α → 拒绝H₀
P ≥ α → 不拒绝H₀

t检验

t检验类型目的适用场景
单样本t检验样本均数与已知总体均数比较判断某指标是否与标准值有差异
两独立样本t检验比较两组独立样本的均数差异实验组vs对照组
配对t检验比较配对样本的均数差异治疗前后、配对设计

卡方检验（χ²检验）

检验类型用途示例
四格表χ²检验两组率的比较新药组vs安慰剂组有效率比较
行×列表χ²检验多组率或构成比比较三种药物有效率比较
配对χ²检验配对设计的两分类数据两种诊断方法的比较

相关与回归

方法适用条件解读
Pearson相关（r）双变量正态分布计量资料|r|<0.3弱；0.3-0.7中；≥0.7强
Spearman相关（rs）不满足正态分布的资料、等级资料计算秩次间的Pearson相关系数
回归方程解读：
方程：Ŷ = 80 + 0.5X（X为年龄，Y为收缩压）
解读：年龄每增加1岁，收缩压平均增加0.5 mmHg

生存分析

方法用途
Kaplan-Meier法估计生存率，制作生存曲线
Log-rank检验比较两条或多条生存曲线的差异
Cox回归多因素生存分析，控制混杂因素，计算HR
HR解读：HR = 2.5 解读为该因素阳性者的死亡风险是阴性者的2.5倍

高级统计方法

Logistic回归

方程：logit(P) = ln[P/(1-P)] = b₀ + b₁X₁ + ... + bpXp

OR值含义
OR = 1无影响
OR > 1危险因素
OR < 1保护因素
OR的95% CI不包含1有统计学意义

诊断试验评价

指标公式含义
灵敏度a/(a+c)真阳性率
特异度d/(b+d)真阴性率
假阳性率b/(b+d)误诊率 = 1-特异度
假阴性率c/(a+c)漏诊率 = 1-灵敏度

ROC曲线

AUC值诊断价值
0.5-0.7较低
0.7-0.9中等
> 0.9较高

第三部分：工具实操

SPSS实操

常用分析操作

  • 描述性统计：分析 → 描述统计 → 频率/描述
  • t检验：分析 → 比较均值 → 独立样本T检验 / 配对样本T检验
  • 卡方检验：分析 → 描述统计 → 交叉表 → 统计量 → 卡方
  • Logistic回归：分析 → 回归 → 二元Logistic
t检验结果解读：
1. 先看Levene检验P值
  • P > 0.05：用第一行（方差齐）结果
  • P ≤ 0.05：用第二行（方差不齐）结果
2. 再看t检验P值

R语言实战

# t检验
t.test(weight ~ group, data = data)           # 独立样本t检验
t.test(before, after, paired = TRUE)         # 配对t检验

# 卡方检验
chisq.test(table(data$group, data$outcome))  # 卡方检验
fisher.test(table(data$group, data$outcome)) # Fisher精确检验

# Logistic回归
glm(outcome ~ var1 + var2, data = data, family = binomial())

第四部分：常见错误与注意事项

常见错误类型

错误类型具体表现正确做法
样本量不足未进行样本量估算根据效应量、显著性水平、检验效力计算
方法选择错误偏态资料用t检验非正态资料用非参数检验
忽视方差齐性方差不齐时仍用t检验采用校正t检验或非参数检验
只报告P值仅报告P < 0.05同时报告效应量和95% CI
P值不等于效应大小！

P值反映的是"如果H₀成立，看到当前数据或更极端数据的概率"，它不能告诉你：
• 效应有多大
• 临床是否重要
• 结果是否可重复
正确报告方式：
降压效果：-12 mmHg（95% CI: -16 to -8 mmHg），P < 0.001

解读：效应量-12mmHg，置信区间不包含0，统计学意义明确

第五部分：总结与资源

统计方法选择

两组独立样本
正态+方差齐 → 独立样本t检验
非正态/方差不齐 → Mann-Whitney U检验
↓
配对样本
正态 → 配对t检验
非正态 → Wilcoxon符号秩检验
↓
多组独立样本
正态+方差齐 → 单因素ANOVA → Tukey HSD
非正态 → Kruskal-Wallis H
↓
计数资料
n≥40，期望值≥5 → χ²检验
n<40或期望值<5 → Fisher精确检验

国际报告规范

规范适用研究类型核心要点
CONSORT随机对照试验样本量计算、随机化、盲法、Flow图
STROBE观察性研究研究设计、混杂因素报告、统计方法
PRISMA系统评价/Meta分析检索策略、筛选流程、证据质量
STARD诊断准确性研究ROC曲线、置信区间

附录：常用公式速查

公式用途
t = (x̄ - μ₀)/(s/√n)单样本t检验
F = MS组间/MS组内方差分析
χ² = Σ(O-E)²/E卡方检验
r = Σ(xi-x̄)(yi-ȳ)/√[Σ(xi-x̄)²Σ(yi-ȳ)²]Pearson相关
OR = (a/c)/(b/d) = ad/bc优势比
HR = exp(b)Cox回归风险比

样本量估算要点

指标含义常规取值
α（显著性水平）Ⅰ类错误概率0.05
β（Ⅱ类错误概率）漏检概率0.2（检验效力1-β=0.8）
δ（效应量）期望发现的最小差异根据文献或预实验估算
